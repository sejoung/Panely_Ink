Install Notes

Android blocks APK installs from outside the Play Store by default. You must allow “Install unknown apps” for the browser or file manager you use to open the APK.

  1. Download the APK on your Android e-ink device.
  2. Open it with your browser or file manager.
  3. When prompted, tap Settings and enable Allow from this source (Android 8+) or Unknown sources (older Android).
  4. Return to the installer and tap Install.

Meebook M7: grant the permission ahead of time via Settings → Device info → Settings → Apps & notifications → Mee OS → Advanced → Install unknown apps, then enable it for the browser or file manager you will use.

The current release artifact is unsigned until project signing is configured.

한국어

Android는 Play 스토어 외부 APK 설치를 기본적으로 차단합니다. APK를 여는 브라우저 또는 파일 관리자에 “알 수 없는 앱 설치” 권한을 허용해야 설치할 수 있습니다.

  1. Android e-ink 기기에서 최신 APK를 내려받습니다.
  2. 브라우저나 파일 관리자에서 APK 파일을 엽니다.
  3. 설치 차단 안내가 뜨면 설정을 눌러 이 출처 허용(Android 8 이상) 또는 알 수 없는 소스(이전 버전)를 켭니다.
  4. 설치 화면으로 돌아와 설치를 누릅니다.

Meebook M7: 설정 → 기기 정보 → 설정 → 앱 및 알림 → Mee OS → 고급 → 알 수 없는 앱 설치 경로에서 사용할 브라우저나 파일 관리자에 권한을 미리 허용해 두면 편합니다.

현재 릴리즈 APK는 프로젝트 서명 설정 전까지 unsigned artifact입니다.
